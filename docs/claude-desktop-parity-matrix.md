## Status vocabulary

- `not-started` — no novel-agent implementation evidence.
- `researching` — a host/DSH/upstream seam is being assessed.
- `red` — a focused test has demonstrated a missing behavior.
- `implemented-unverified` — plugin code or composition exists, but the required
  visible host interaction or lifecycle evidence is incomplete.
- `verified` — only the stated scope has current evidence.
- `blocked` — a concrete external issue prevents the next action.

An upstream source or an isolated local smoke does not make full product parity
`verified`. Production and user acceptance are recorded separately.
