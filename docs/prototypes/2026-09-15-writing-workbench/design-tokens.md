# 设计 token 表与组件清单 · 小说协作写作工作台（原型）

配套交付物：`index.html`（单文件可点击原型）。
视觉方向：**纸墨书房** —— 暖纸底、墨色文字、单一朱砂红强调色；安静、耐读，适合每天长时间面对。

Token 全部写在 `index.html` 的 `:root`（日间）与 `[data-theme="night"]`（夜间）中；组件只引用变量，不出现散落的硬编码色值。

## 2. 字体与字阶

| 角色 | 字体栈 | 说明 |
| --- | --- | --- |
| 正文与标题 | `"Source Han Serif SC","Noto Serif SC","Songti SC",SimSun,serif` | 宋体类衬线，全部为系统字体，离线可用 |
| 界面控件 | `"PingFang SC","Microsoft YaHei",system-ui,sans-serif` | 管理类界面 |
| 等宽 | `ui-monospace,"JetBrains Mono",Menlo,Consolas,monospace` | 数字对齐与**诊断模式专用** |

| Token | 值 | 用途 |
| --- | --- | --- |
| `--fs-12` | 12px | 标签、徽标、元信息 |
| `--fs-13` | 13px | 管理界面主体（密度中等） |
| `--fs-14` | 14px | 界面标题、卡片标题行 |
| `--fs-15` | 15px | 卡片标题、章节名 |
| `--fs-17` | 17px / 行高 1.9 | **正文阅读**（16–18px 区间取中值） |
| `--fs-18` | 18px | 抽屉/页面标题 |
| `--fs-22` | 22px | 页面主标题、章节标题 |

中文阅读规范（原型中 `.read-body`、`.pr-text` 均满足）：
正文 17px、行高 1.9、行宽 `max-width: 680px`（≈ 40 字）、段距 `0.9em`、`text-align: left`（不强制两端对齐）；阅读区底色用 `--paper-2`，比界面底更暖/更亮。
数字（字数、版本、条数）统一加 `.num`：等宽 + `tabular-nums` 对齐。

> 与默认基线的差异：基线行高上限 1.75，本设计按用户中文长文阅读要求提升到 1.9。

## 3. 间距与栅格

- 基准：**4px 栅格**；常用档位 4 / 8 / 12 / 16 / 20 / 24 / 32 / 48。
- 管理界面密度中等：卡片内距 14–16px，区块间距 14–20px，页面内距 20–22px。
- 布局栅格：工作台 = 左导航 228px + 主区自适应 + 右侧上下文栏 288px；窄窗 1280 时导航折叠为 60px、右栏转为浮层。
- 画布基准 1440×900；原型按视口等比缩放（`fitStage()`），宿主最小 1280 宽可用。

## 5. 动效

| Token | 值 | 说明 |
| --- | --- | --- |
| `--t-fast` | 150ms | hover / 颜色反馈 |
| `--t-base` | 220ms | 弹层、折叠、状态切换 |
| `--t-slow` | 300ms | 抽屉进出 |
| `--ease` | `cubic-bezier(.2,0,0,1)` | 进入 ease-out，退出 ease-in |

- 只动 `transform` 与 `opacity`；列表错峰 30–50ms（原型中列表用统一过渡，未做逐项延迟）。
- 全站支持 `prefers-reduced-motion: reduce`（动画与过渡降到 0.01ms）。
- 焦点环：`--focus-ring`（朱砂半透明描边），`:focus-visible` 时 2px 朱砂实线 + 2px 偏移。

## 7. 关键链路与无障碍

- 关键链路各 ≤3 击：
  1. 地图 → 人物节点（档案抽屉）→ 出场章节 → 正文阅读；
  2. Chat 回合尾卡 → 接受本章 → 影响预览 → 确认（R5→R6 同步）；
  3. 写作台 → 待审提案入口 → 接受本章。
- 键盘：Tab 顺序为导航 → 主区 → 上下文栏；Esc 关闭抽屉/弹层/设置；Enter 确认主按钮；抽屉与弹窗打开时焦点困住；图谱节点与折叠气泡可用 Tab 聚焦、Enter 打开。
- 对比度：正文与纸底 ≥ 4.5:1（`--ink` / `--ink-2` 均满足），图标与图形 ≥ 3:1；状态永不只靠颜色（均配文字或形状）。
- 日夜：写作台头部与设置面板均可切换；夜间为深暖灰（非纯黑），文字为暖白；宿主外壳使用独立中性灰 token。

## 8. 已知取舍（原型范围）

- 关系图谱为**内联 SVG 手工布局**（势力/地点分簇 + 环形分布 + 钉位），未引入任何图库；40+ 人物场景通过「主人物 + 折叠 + 搜索聚焦 + 本卷过滤」控制密度。
- 沙盒推演（MiroFish）仅实现未连接态：说明卡 + 连接指引 + 置灰的实验列表/表单/详情。
- 正文阅读为节选（每章 2–6 段，渐隐收尾）；第 7–12 章为「计划中」状态页。
