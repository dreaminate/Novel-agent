## 3. 原型里真的能点通的交互

- 地图：点节点 → 右栏切成该人物摘要、相关边加亮其余淡出；双击节点（或按 D）→ 人物档案抽屉；拖拽节点钉位、双击/抽屉内取消钉位；滚轮与按钮缩放、拖背景平移；按势力 / 按地点分簇；搜索人物自动定位；「只看本卷出场」过滤；簇内「+N」展开次要人物；图例；边 hover 出双向语义与未了债务。
- 提案：逐条接受 / 拒绝（默认接受，拒绝就地留理由）、出处锚点跳正文并高亮、影响预览弹层、「接受本章」→ loading「正在计算影响…」→ 写入 R6 → 轻提示；「只接受设定变更」单独走一条路径；过期提案只能丢弃。
- 版本：对比弹层、回滚二次确认；回滚后顶栏版本号、地图关系、伏笔状态、时间线、右栏活动行一起回退（回滚到 R5 会把第 6 章提案恢复成待审）。
- 输入条：线程切换 / 新建线程、`/` 命令候选、`@` 人物与章节引用、继续写下一章（loading → 生成提示）、审阅本章（按提案状态改变行为）、模型与权限指示。
- 设置：主题（跟随系统 / 日间 / 夜间）、正文字号 16–18px、阅读行宽 34 / 40 字、线程里是否显示工具活动。
- 进阶面：插件挂载/卸载、preset 切换、Jobs 重试、诊断原始数据。
- 键盘：Tab 顺序 = 左栏 → 主画布 → 右栏 → 输入条；图谱节点可聚焦，Enter 选定、D 打开档案；Esc 关抽屉 / 弹层 / 设置；弹层内 Tab 循环、Enter 触发主按钮；所有可聚焦元素有陶土焦点环。
- 记忆：当前屏幕、主题、版本与窄窗开关写入 `localStorage`，刷新后回到上次位置。

## 5. 已知边界与未验证项

- 这是设计产物，不是产品代码：不接入 DSH、不写 `packages/`，所有数据是内嵌的样例数据，刷新后按 `localStorage` 回到上次屏幕，但不会与真实项目状态同步。
- 时间与状态类文案（「今天 21:04」「2 小时前」「48s」）是固定样例值，用于展示信息结构，不是真实运行时间。
- 推演（沙盒侧车）按 brief 只做未连接态：说明卡 + 连接指引 + 置灰入口与表单。
- 未做浏览器实测的部分：观感、动效手感、40+ 人物真实密度、以及「三条关键链路 ≤3 击」的人工点选计时。建议在浏览器里逐条对照 brief 第 8 节复核。
- 原型文件约 2.4k 行（单文件内嵌全部屏幕），超出「单文件 ≤1000 行」的通用建议；这是「一个 HTML 文件 + 15 组屏幕」这条硬要求下的取舍。
- **本次没有取得的渲染截图**：导出用命令 `od export … --format image` 在本机 Electron 运行时里启动失败（`Unable to find helper app` / GPU 进程退出），沙箱内外各试一次均未产出图片，因此视觉结论来自静态检查而非渲染图。已完成的机器检查见下节。

### 已完成的自动检查（2026-09-16）

- `node --check` 通过：原型内嵌脚本无语法错误。
- 运行时冒烟测试（Node + 最小 DOM 桩，覆盖 12 组作者屏 × 5 种提案状态 × 7 个进阶面板）：全部渲染路径无异常；点击 / 键盘 / 滚轮 / 拖拽 / 输入事件处理器逐个触发无异常。
- 内容断言全部通过，逐条核对了：提案审阅头部行、过期态与「只能丢弃」、接受设定·拒绝正文结果态（右栏活动行**逐字**为「已接受 5 条设定变更，正文未接受」）、影响预览行、R6 版本摘要、正文锚点高亮（`<mark>`）、章节状态徽标「已接受 / 待审 / 计划中 / 有未收束债务」、以及空项目 / 缺插件 / 侧车未连接 / AI 无输出四类边界文案。
- 术语审计：在 12 组作者屏 × 5 种提案状态下扫描 `JSON / delta / Canon / 控制包 / 提交 / 执行`，命中 0 —— 这些词只出现在进阶面与诊断面（brief 明确允许）。
- 对比度实算：正文与界面文字 4.9:1–15.0:1，状态徽标 4.7:1–7.3:1，焦点环 3.1:1；明细与偏离说明写在 `design-tokens.md` 第 1、6 节。
