# 设计 token 表 · DSH 小说模式工作台（2026-09-16 原型 v4）

配套交付物：`novel-mode-workbench.html`（单文件可点击原型，内嵌 CSS/JS，无外部资源）。
视觉方向：**Claude Code 桌面版的暖灰语言** —— 暖灰四档底色、陶土色单一强调、克制的 0.5–1px 细线、小圆角、低阴影；等宽字体只出现在数字、版本号与进阶/诊断面。

token 全部写在原型的 `:root`（日间）与 `html[data-theme="night"]`（夜间）中，组件只引用变量，不出现散落的硬编码色值。

### 1.3 强调色（唯一）

| Token | 日间 | 夜间 | 用途 |
| --- | --- | --- | --- |
| `--accent-brand` | `15 63.1% 59.6%`（陶土 `#D97757`） | 同值 | 实心主按钮底、待审徽标、图谱选中、焦点环 |
| `--accent-brand-deep` | `15 54.2% 51.2%` | `15 60% 53%` | 强调色 hover、实心按钮描边 |
| `--accent-text` | `15 55% 38%`（`#96462C`） | `15 63.1% 59.6%` | **强调色文字**（链接、当前项、标签文字） |
| `--on-accent` | `20 14% 10%`（`#1D1816`） | 同值 | 陶土实心底上的文字 |

强调色用法：陶土既当底色也当文字色时**不共用同一档**——底用 `--accent-brand`、底上文字用 `--on-accent`（5.6:1），文字则改用更深一档的 `--accent-text`（日间 on `--bg-100` 6.2:1），避免小字陶土落在近白底上掉到 3:1。

## 3. 间距、栅格与尺寸

- 间距基数为 4px：`--s1 4 / --s2 8 / --s3 12 / --s4 16 / --s5 20 / --s6 24 / --s7 32`。
- 主画布左右内边距 24px，卡片内距 16px，列表行高 34–40px。
- 应用栅格（定宽舞台，画布基准 1440×900）：**顶栏 44px + 主区自适应 + 底部输入 88px**；横向 **左栏 248px + 主画布自适应 + 右栏 296px**。
- 窄窗演示（`--app-w: 1280px`）：左栏折叠为 58px 图标栏（hover / focus 出 tooltip），右栏默认收起、可按需浮层展开，主画布自适应；应用层不产生横向滚动。
- 触摸/点击目标：常用控件 26–32px 高，主按钮 32–36px；图谱节点命中区包含整圆与标签区。

## 6. 已知取舍与偏离（诚实记录）

1. **夜间细线提亮**：按实测结构，夜间 `--border-100` 与 `--bg-200` 同值（`30 3.3% 11.8%`），1px 线在暖深灰上不可辨识；原型按两档提升到 `30 4% 22%`（`--border-200` 到 `30 5% 30%`）。
2. **陶土作为文字色**：实测陶土 `#D97757` 落在近白底上只有约 3.1:1，够图标与大字、不够 12–13px 小字；因此新增 `--accent-text`（日间 `15 55% 38%`，6.2:1），夜间直接用陶土本体（4.9:1）。
3. **细线对比**：容器细线（`--border-100`，日间对白底 1.5:1）沿用「克制的细线」这套视觉语言，属装饰性分隔；可交互控件的描边用 `--border-200`，焦点态则一定换成 3.1:1 的陶土 2px 描边 + 2px 偏移，满足焦点可见性。
4. **形状与密度**：圆角、内距、行高均按本 brief 的 token 骨架执行；正文行高取 1.85（高于通用上限 1.75），按中文长文阅读要求。
